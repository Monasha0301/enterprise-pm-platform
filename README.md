# Enterprise Project Management & Team Collaboration Platform

> AI-powered project management for teams: plan sprints, track tasks, collaborate in real time, and get AI assistance.

![Status](https://img.shields.io/badge/status-in%20planning-yellow)
![License](https://img.shields.io/badge/license-MIT-blue)

## 📌 Overview

A scalable, full-stack platform that helps teams plan, track, and deliver
software projects. It combines a modern web app, an admin dashboard,
a microservice backend, and AI features such as task generation and sprint
summaries.

> 🚧 **This project is under active development.** Documentation and code
> are being added phase by phase.

## 🎯 Goals

- Build a production-style enterprise application
- Practise professional engineering: requirements, design, testing, CI/CD
- Demonstrate clean architecture, SOLID principles, and cloud deployment

## 🧰 Planned Tech Stack

| Layer          | Technology                                   |
| -------------- | -------------------------------------------- |
| Web app        | React, Next.js, TypeScript, Tailwind, shadcn/ui |
| Admin panel    | Angular, Angular Material                    |
| Backend        | NestJS, Spring Boot (microservices)          |
| Database       | PostgreSQL (Supabase)                        |
| Auth / Storage / Realtime | Supabase                          |
| DevOps         | Docker, GitHub Actions, Vercel, Render/Railway |
| Testing        | Jest, Cypress, Postman                       |
| Docs           | Markdown, Swagger/OpenAPI                    |
